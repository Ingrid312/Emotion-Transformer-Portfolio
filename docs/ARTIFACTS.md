# Saved evaluation artifacts

Three original files were supplied after the training notebooks were recovered. They are included without changing their numeric contents:

| Public path | Original supplied file | Role |
|---|---|---|
| `artifacts/thresholds.json` | `thresholds.json` | Ordered labels and eight calibrated threshold values |
| `results/original_hierarchical_performance.csv` | `final_test_performance_metrics.csv` | Hierarchical model's per-label and aggregate evaluation |
| `results/original_flat_bert_performance.csv` | `standard_bert_performance.csv` | Flat BERT's saved per-label and aggregate evaluation |

## What was checked

The threshold label order exactly matches the model's canonical eight labels. All eight values are finite and within [0,1]. The original floating-point values are retained; rounded values should be used only for display.

The reports' per-label precision, recall, F1 and support are mathematically consistent. Inferred integer TP/FP/FN counts reproduce Micro-F1, micro precision/recall and macro/weighted averages. The hierarchical per-label support matches every label in the recovered 1,207-post test split, totaling 4,425 positive assignments.

| Saved report | Micro-F1 | Macro-F1 | Positive label assignments |
|---|---:|---:|---:|
| Hierarchical | 0.807333616 | 0.772465839 | 4,425 |
| Flat BERT | 0.834303627 | 0.799435640 | 2,260 |

The hierarchical report implies TP=3,809, FP=1,202 and FN=616. Using 1,207 posts from the notebook, its Hamming loss is 0.1882767, agreeing with the thesis's rounded calibrated value. These are counts inferred from aggregate metrics; they are not recomputed from per-example predictions.

The hierarchical Suicide Intent precision/recall/F1 are 0.750741840 / 0.848993289 / 0.796850394. The supplied threshold for this label is approximately 0.63. The threshold file has no model hash, so its pairing with a specific checkpoint is not independently verified.

## Differences from the thesis table

The supplied hierarchical CSV has Macro-F1 0.772465839 (0.7725 to four decimals), while the thesis table states 0.773. The Flat BERT CSV has Macro-F1 0.799435640, matching epoch 6 in the supplied log. The thesis's 0.802 Macro-F1 appears at epoch 8, alongside a slightly different Micro-F1. Original thesis numbers remain preserved as historical reports; the README now uses the saved CSV values.

## Verification limits

No checkpoint bytes or per-example prediction arrays were supplied, and neural inference was not rerun. Internal aggregate consistency does not prove the underlying predictions are correct. The two reports have different evaluation populations; the Flat BERT notebook selects epochs on its set named `test`, so this set functions as development data. A strict comparison still needs fresh neural runs on the prepared shared train/validation/test split.

The pre-calibration FP count of 1,313 comes from the thesis. The calibrated CSV supports the post-calibration aggregate count of 1,202; it cannot independently verify the before-calibration predictions or threshold-selection process.

The private checkpoint screenshot is excluded from the public package. No large weights or local account paths are redistributed.

## Repeat the checks

From the repository root, run:

```bash
python scripts/verify_saved_reports.py
```

The resulting `results/saved_artifact_verification.json` records the checks, aggregate inferred counts, source-file SHA-256 values and limitations. Freshly trained weights should use newly calibrated thresholds generated by that training run.
